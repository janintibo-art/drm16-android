Deux couches par instrument

C'est ce qui définit la machine. Chaque instrument a une voix analogique — couche A, avec ses TUNE, DECAY et deux réglages propres — et une couche d'échantillon B, prise dans la bibliothèque. Le potard A / B les mélange : à gauche l'analogique seul, à droite l'échantillon seul, entre les deux les deux ensemble. Le bouton SAMPLE B fait défiler les sons.

Morphing

SET A mémorise l'état de tous les potards, SET B un second état, et le curseur MORPH passe de l'un à l'autre en interpolant chaque réglage. Un kit sec d'un côté, un kit long et accordé grave de l'autre, et tout le passage entre les deux sous le doigt.

Tant que les deux états sont posés, le curseur commande et les potards ne s'entendent plus. Repressez SET A ou SET B pour leur rendre la main.

Sous-pas

SUB STEP change ce que font les seize touches : chacune règle alors le nombre de coups de ce pas, de un à quatre. Un point jaune marque les pas concernés. C'est le roulement de la TR-1000, et il se règle pas par pas au lieu d'être global.

Effets

ANALOG FX ne touche que la couche analogique : un filtre passe-bas et une saturation, comme sur l'appareil où le circuit est réellement analogique. REVERB et DELAY, eux, reçoivent les deux couches.

Ce qui diffère

Huit banques de seize motifs, mais pas de mode chanson ni d'échantillonnage par l'entrée. Les six potards assignables C1 à C6 de la vraie machine sont remplacés par les réglages fixes de chaque instrument : sans écran de menu, des potards sans affectation visible n'auraient rien voulu dire.
