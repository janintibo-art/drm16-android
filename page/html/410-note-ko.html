Un échantillonneur de poche

Seize emplacements, un séquenceur de seize pas, seize motifs. Tout tient sur seize touches, et c'est volontaire : cette machine se joue plus qu'elle ne se programme.

En mode normal, les huit premières touches sont mélodiques et les huit dernières sont des percussions. Le bouton CHROMA transforme les seize touches en clavier de seize demi-tons : le son mélodique choisi est joué de -7 à +8 demi-tons. Sélectionnez d'abord l'un des huit sons mélodiques en mode SOUND, puis activez CHROMA. C'est ce comportement chromatique qui permet de jouer une ligne mélodique avec un seul échantillon.

Les trois modes des touches

  • SOUND — les touches jouent. Avec RECORD allumé, elles écrivent aussi dans le motif : en lecture, la frappe se pose sur le pas le plus proche ; à l'arrêt, elle bascule le pas courant. En mode CHROMA, la hauteur choisie est mémorisée dans le motif ; retoucher la même hauteur l'efface.
  • PATTERN — les touches choisissent le motif, de 1 à 16.
  • FX — les touches choisissent l'effet.

WRITE efface le motif courant, après confirmation. C'est le seul geste destructeur de la machine.

Swing

Le curseur SWING va de 50 %, rythme droit, à 75 %, groove très marqué. Il retarde les pas 2, 4, 6… sans déplacer les autres, et peut être réglé pendant PLAY pour entendre immédiatement le résultat. La valeur est sauvegardée avec le PO-33 ; les anciens projets restent à 50 %. Sur la machine physique, le même réglage se fait en maintenant BPM et en tournant le potentiomètre A.

Les seize effets au poing

En mode FX, les seize pads reprennent l'ordre de la machine physique. Choisissez un effet, lancez PLAY, puis maintenez FX : la transformation reste active jusqu'au relâchement. Avec RECORD allumé — le mode d'écriture de cette façade — l'effet est aussi mémorisé sur chaque pas traversé. Choisissez SANS EFFET puis maintenez FX pour effacer une plage enregistrée.

  1. BOUCLE 1/16 — fige le pas capturé et le répète à chaque double croche.
  2. BOUCLE 1/12 — même principe sur une grille ternaire de douze impulsions.
  3. BOUCLE COURTE — deux répétitions serrées par pas.
  4. BOUCLE MINI — quatre répétitions très courtes par pas.
  5. UNISON — deux voix légèrement désaccordées.
  6. UNISON BAS — ajoute une voix une octave plus bas.
  7. +1 OCTAVE — transpose la lecture vers le haut.
  8. -1 OCTAVE — transpose la lecture vers le bas.
  9. STUTTER ×4 — répète le pas courant quatre fois avec une légère décroissance.
  10. STUTTER ×3 — variante ternaire en trois frappes.
  11. SCRATCH — alterne lecture avant et arrière sur deux gestes courts.
  12. SCRATCH RAP. — quatre alternances plus serrées.
  13. QUANTIF. 6/8 — transforme chaque groupe de quatre pas en trois impulsions ternaires.
  14. REDÉMARRAGE — relit le motif depuis son premier pas tant que FX reste tenu.
  15. REVERSE — lit chaque échantillon à l'envers.
  16. SANS EFFET — position neutre.

Les quatre boucles mémorisent le pas courant au moment où FX est enfoncé. Le swing reste actif pour les effets binaires ; BOUCLE 1/12 et QUANTIF. 6/8 utilisent leur propre grille ternaire.

Parameter Locks

Le panneau PARAMETER LOCK mémorise une variation pour chaque pas du motif. Choisissez le pas, puis un paramètre et sa valeur avant d'appuyer sur ÉCRIRE. PITCH transpose le son, START déplace son début, LENGTH raccourcit sa durée et TONE ferme le filtre. La variation s'applique à toutes les frappes de ce pas, y compris pendant les boucles et les stutters. EFFACER retire seulement le paramètre choisi. Les anciens motifs restent compatibles et commencent sans verrou. L'édition des verrous se fait à l'arrêt ; la lecture et les autres modes les verrouillent pour éviter une modification involontaire.

En MIDI

Les seize emplacements répondent à seize notes d'affilée à partir de la note de base réglée dans la notice générale. La machine reçoit donc aussi bien un clavier qu'une grille de pads.
