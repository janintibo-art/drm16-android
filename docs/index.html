DRM16

Vingt-cinq boîtes à rythmes et un rack Eurorack,
dans une seule application Android.

Télécharger pour Android Android 7 minimum · environ 2 Mo · hors ligne, sans compte, sans publicité

Sur ordinateur

La même application, dans une fenêtre.

Windows — l'installeur, environ 8 Mo. Windows affichera un avertissement d'éditeur inconnu : c'est le cas de tout programme non signé par un certificat payant. Choisissez Informations complémentaires puis Exécuter quand même.

macOS, Linux, ou sans rien installer — téléchargez l'archive drm16-pc.zip, décompressez tout le dossier, puis ouvrez drm16.html dans votre navigateur. Studio, Nexus et leurs sons sont inclus. La notice du ZIP explique le lancement local si le navigateur bloque leurs sons depuis le disque.
Le HTML seul reste disponible, sans ces fichiers supplémentaires.

L'installeur Windows offre le MIDI externe et la bibliothèque native de fichiers. La version navigateur n'a pas ces fonctions natives ni les téléchargements archive.org ; l'export WAV passe par les téléchargements du navigateur. La conservation des motifs dépend de la mémoire locale autorisée par le navigateur et de l'adresse utilisée.

Ce qu'il y a dedans

  • Vingt-cinq machines : six Electribe, quatre TR et la RD-6, deux MPC, la TD-3, l'Oberheim DMX, la volca sample, la CR-5000, la DrumBrute Impact, la TR-1000, les DRM-16 et DRM-32, et une machine d'archive qui reprend quatre cent soixante-dix boîtes documentées sur archive.org.
  • Un rack Eurorack de quatre-vingt-neuf modules à câbler soi-même, huit racks gardés séparément, et vingt-quatre montages tout faits rangés par genre.
  • MIDI en entrée et en sortie, horloge comprise : les vingt-cinq machines répondent aux notes qu'elles émettent elles-mêmes.
  • Export WAV, bibliothèque de sons, enregistreur MIDI, éditeur en rouleau.
  • Une notice complète en français, machine par machine, dans l'application.

Installer

  1. Touchez le bouton de téléchargement ci-dessus.
  2. Ouvrez le fichier téléchargé. Android demandera d'autoriser l'installation depuis cette source : c'est la question posée pour toute application distribuée hors du Play Store.
  3. Si une version précédente est déjà installée, celle-ci se met par-dessus sans effacer vos motifs.

Aucune permission réseau n'est nécessaire pour jouer. Elle ne sert qu'à la machine d'archive, qui va chercher des sons sur archive.org à la demande.

Le code

Tout tient dans un seul fichier HTML, moteur audio compris, dans une coque Android minimale. Le code et la notice sont en français. Voir le dépôt · Toutes les versions

Projet personnel, sans lien avec Roland, Akai, Korg, Arturia, Behringer, Oberheim ni aucun autre fabricant. Les noms d'appareils servent à dire de quoi le son s'inspire ; aucun échantillon ni aucun circuit d'origine n'est utilisé — tout est synthétisé.
